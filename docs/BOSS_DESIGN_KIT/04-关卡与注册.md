# 04 · 关卡与注册

> 把你的 7 层区域接进游戏。

---

## 一、区域结构

```
六大天王（7 层，从 26F 开始）
├── 26F  第1层  法术王场地
├── 27F  第2层  远程王场地
├── 28F  第3层  Debuff 王场地
├── 29F  第4层  召唤王场地
├── 30F  第5层  坦克王场地
├── 31F  第6层  全能王场地
└── 32F  第7层  NPC 结算厅
```

---

## 二、步骤 1：注册区域

打开 `core/.../endcontent/challenge/ChallengeArea.java`：

### 2.1 加注册项

找到注册表区域，加一行：

```java
//六大天王（id=7，7 层）
public static final ChallengeArea SIX_KINGS = new ChallengeArea(7, "六大天王", 7, true);
```

**参数说明**：
| 参数 | 含义 |
|---|---|
| `7` | **区域 id**（必须唯一，且决定进入顺序） |
| `"六大天王"` | 显示名 |
| `7` | **占用层数** |
| `true` | `implemented`（true = 可勾选） |

### 2.2 加进 ALL 数组

```java
public static final ChallengeArea[] ALL = {
    HOLLOW, GALAXY, IBERIA, GAVIAL, SIESTA, SIX_KINGS
};
```

> ⚠️ 忘了这步 → 界面上看不到你的区域

---

## 三、步骤 2：路由关卡

同一个文件里，找到 `createAreaLevel(int areaId, int floorIn, int depth)`，加分支：

```java
if (areaId == SIX_KINGS.id) {
    switch (floorIn) {
        case 0: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel1();
        case 1: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel2();
        case 2: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel3();
        case 3: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel4();
        case 4: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel5();
        case 5: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsLevel6();
        default: return new com.shatteredpixel.shatteredpixeldungeon.levels.boss.SixKingsHallLevel();  // 第7层 NPC
    }
}
```

> `floorIn` 是**区内偏移**（0 起），不是绝对层号。

## 四、步骤 3：NPC 结算厅

第 7 层放一个 NPC，模板：

```java
package com.shatteredpixel.shatteredpixeldungeon.actors.mobs.npcs.sixkings;

import com.shatteredpixel.shatteredpixeldungeon.actors.mobs.npcs.NTNPC;
import com.shatteredpixel.shatteredpixeldungeon.sprites.SixKingsGuideSprite;

/** 六大天王 · 结算 NPC */
public class SixKingsGuide extends NTNPC {

    {
        spriteClass = SixKingsGuideSprite.class;
        alignment = Alignment.NEUTRAL;    // 中立，不打人
    }

    @Override
    public boolean interact(Char c) {
        // 弹出对话窗口
        // GameScene.show( new WndSixKingsGuide( this ) );
        return true;
    }
}
```

NPC 层的 `createMobs()`：

```java
@Override
protected void createMobs() {
    SixKingsGuide guide = new SixKingsGuide();
    guide.pos = (HEIGHT / 2) * WIDTH + (WIDTH / 2) + 2;
    GameScene.add( guide );
}
```

### 键名规则（**必须记牢**）

```
键 = 完整包路径（去掉 com.shatteredpixel.shatteredpixeldungeon.）+ 类名小写 + .键

类：com.shatteredpixel.shatteredpixeldungeon.actors.mobs.bosses.sixkings.SorcererKing
                                                       └────────── 去掉这段 ──────────┘
键：actors.mobs.bosses.sixkings.sorcererking.name
```

**自查**：
```powershell
cd E:\破碎的地牢
python _tools\find_nofound.py
```
→ 应该报告**零缺失**。若报告某某键缺失，说明键名写错了。

## 七、测试路径

```
1. 进入游戏 → 选英雄 → 勾选「六大天王」
2. 用「深渊传送符」跳到 25F，或正常打到 25F
3. 26F 起依次遭遇六王
4. 32F 遇到 NPC
```

**快速跳层**：便利挑战给的**深渊传送符**可以逐站跳层（25→26→31→32→33→38）。
