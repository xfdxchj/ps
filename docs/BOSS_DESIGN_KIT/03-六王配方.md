# 03 · 六大天王配方

> 六种类型的**具体实现要点**。每种给：数值建议 + 核心机制 + 可复制代码片段。

---

## 总览

| # | 王 | 核心数值特征 | 关键机制 |
|---|---|---|---|
| 1 | **法术王** | 中等血，高伤 | 随机元素 AOE |
| 2 | **远程王** | 低血，中伤 | 远射 + 后撤 |
| 3 | **Debuff 王** | 中等血 | 命中叠负面 |
| 4 | **召唤王** | **低血** | 定期召怪 |
| 5 | **坦克王** | **超高血 + 高防** | 减伤 + 反伤 |
| 6 | **全能王** | 高血 + 三阶段 | 血量触发变身 |

**建议顺序**：法术 → 远程 → Debuff → 召唤 → 坦克 → 全能

---

## 🔮 1. 法术王

### 数值建议
```java
HT = 260;  baseMin = 20; baseMax = 32;
baseMinDef = 4; baseMaxDef = 10;
baseAcc = 34;  baseEva = 16;
```

### 核心机制：随机元素 + AOE

```java
/** 元素类型 */
private enum Elem { FIRE, FROST, SHOCK, POISON }
private Elem curElem = Elem.FIRE;

private int spellCd = 2;

@Override
protected boolean act() {
    if (spellCd-- <= 0 && enemy != null && enemySeen) {
        curElem = Elem.values()[Random.Int(Elem.values().length)];  // 随机换元素
        castElemSpell();
        spellCd = Random.IntRange(2, 4);
        spend(TICK);
        return true;
    }
    return super.act();
}

private void castElemSpell() {
    Char target = enemy;
    if (target == null) return;

    // 视觉：让 Boss 闪对应颜色
    switch (curElem) {
        case FIRE:   sprite.flash();  break;
        case FROST:  sprite.flash();  break;
        case SHOCK:  sprite.flash();  break;
        case POISON: sprite.flash();  break;
    }

    // 伤害
    int dmg = Random.NormalIntRange(baseMin, baseMax);
    target.damage(dmg, this);

    // 附加元素效果
    switch (curElem) {
        case FIRE:
            Buff.affect(target, Burning.class).reignite(target);
            break;
        case FROST:
            Buff.prolong(target, Chill.class, 5f);
            break;
        case SHOCK:
            Buff.prolong(target, Paralysis.class, 1f);
            break;
        case POISON:
            Buff.affect(target, Poison.class).set(8);
            break;
    }

    // AOE：对目标周围也造成伤害
    for (int n : PathFinder.NEIGHBOURS8) {
        Char c = Actor.findChar(target.pos + n);
        if (c != null && c != target && c != this && c.alignment != alignment) {
            c.damage(dmg / 2, this);
        }
    }
}
```

### 变体思路
- **元素轮换**：按 火→冰→雷 固定顺序（玩家可预判）
- **元素免疫**：当前元素免疫同类伤害（增加策略性）
- **反元素**：受伤时切换成克制元素

## 🏹 2. 远程王

### 数值建议
```java
HT = 200;  baseMin = 14; baseMax = 22;
baseMinDef = 3; baseMaxDef = 8;
baseAcc = 38;  baseEva = 24;   // 高闪避
```

### 核心机制：保持距离

```java
private static final int IDEAL_RANGE = 5;   // 理想射程
private static final int MIN_RANGE   = 3;   // 太近就后撤

@Override
protected boolean act() {
    if (enemy == null || !enemySeen) return super.act();

    int dist = Dungeon.level.distance(pos, enemy.pos);

    // 距离足够 -> 射击
    if (dist >= IDEAL_RANGE) {
        shoot(enemy);
        spend(TICK);
        return true;
    }

    // 太近 -> 后撤
    if (dist <= MIN_RANGE) {
        if (retreat()) {          // 成功后撤
            spend(TICK);
            return true;
        }
        // 无路可退 -> 硬打
    }

    return super.act();
}

/** 射击：沿直线打，被墙挡住则无效 */
private void shoot(Char target) {
    Ballistica shot = new Ballistica(pos, target.pos, Ballistica.PROJECTILE);
    if (shot.collisionPos == target.pos) {
        // 命中
        target.damage(Random.NormalIntRange(baseMin, baseMax), this);
        // 视觉：可以加 Beam 或 MagicMissile
    } else {
        // 被挡住，打偏（浪费一回合，给玩家机会）
    }
}

/** 后撤：找一个离玩家更远的可行格 */
private boolean retreat() {
    int best = -1, bestDist = Dungeon.level.distance(pos, enemy.pos);

    for (int n : PathFinder.NEIGHBOURS8) {
        int c = pos + n;
        if (!Dungeon.level.passable[c]) continue;
        if (Actor.findChar(c) != null) continue;
        int d = Dungeon.level.distance(c, enemy.pos);
        if (d > bestDist) { bestDist = d; best = c; }
    }

    if (best != -1) {
        move(best);
        return true;
    }
    return false;
}
```

### 变体思路
- **高台**：站在固定位置，玩家必须绕路
- **连射**：低伤害但每回合多次
- **标记**：给玩家上标记，之后攻击必中

## ☠️ 3. Debuff 王

### 数值建议
```java
HT = 300;  baseMin = 10; baseMax = 16;   // 伤害不高
baseMinDef = 6; baseMaxDef = 12;
baseAcc = 30;  baseEva = 14;
```

### 核心机制：命中叠负面

```java
public boolean attackHook(Char enemy) {
    // 每次命中随机施加一种负面
    applyRandomDebuff(enemy);
    return false;
}

private void applyRandomDebuff(Char target) {
    switch (Random.Int(6)) {
        case 0:
            Buff.prolong(target, Weakness.class, 8f);       // 降低伤害
            break;
        case 1:
            Buff.prolong(target, Vulnerable.class, 8f);     // 增加受伤
            break;
        case 2:
            Buff.prolong(target, Blindness.class, 5f);      // 失明
            break;
        case 3:
            Buff.affect(target, Poison.class).set(10);      // 中毒
            break;
        case 4:
            Buff.prolong(target, Slow.class, 5f);           // 减速
            break;
        case 5:
            Buff.prolong(target, Cripple.class, 5f);        // 残废
            break;
    }
}

// ── 额外：光环型 Debuff（每回合给附近敌人上状态）──
@Override
protected boolean act() {
    if (Dungeon.level.distance(pos, Dungeon.hero.pos) <= 3) {
        Buff.prolong(Dungeon.hero, Weakness.class, 2f);
    }
    return super.act();
}
```

### 变体思路
- **诅咒叠加**：同一个负面叠多层，层数越多效果越强
- **转移**：把玩家身上的增益偷过来
- **禁疗**：让玩家的治疗无效

## 👥 4. 召唤王

### 数值建议
```java
HT = 220;            // **血量最低**（本体脆，靠小弟）
baseMin = 12; baseMax = 18;
baseMinDef = 2; baseMaxDef = 6;    // 防御也低
baseAcc = 28;  baseEva = 30;       // 高闪避自保
```

### 核心机制：定期召唤 + 数量上限

```java
private int summonCd = 2;
private static final int MAX_MINIONS = 5;

@Override
protected boolean act() {
    if (summonCd-- <= 0 && countMinions() < MAX_MINIONS) {
        summon();
        summonCd = Random.IntRange(4, 7);
        spend(TICK);
        return true;
    }
    return super.act();
}

private int countMinions() {
    int n = 0;
    for (Mob m : Dungeon.level.mobs.toArray(new Mob[0])) {
        if (m != this && m.alignment == alignment) n++;
    }
    return n;
}

private void summon() {
    // 选一种小弟
    Mob minion;
    switch (Random.Int(3)) {
        case 0:  minion = new Bat();     break;
        case 1:  minion = new Rat();     break;
        default: minion = new Snake();   break;
    }

    int cell = Dungeon.level.randomRespawnCell(this);
    if (cell == -1) return;      // 没地方放

    minion.pos = cell;
    GameScene.add(minion);
    minion.state = minion.HUNTING;
}

// ── 本体死亡时小弟也跟着死（可选）──
@Override
public void die(Object cause) {
    super.die(cause);
    for (Mob m : Dungeon.level.mobs.toArray(new Mob[0])) {
        if (m != this && m.alignment == alignment) {
            m.die(null);
        }
    }
}
```

### 变体思路
- **牺牲**：吃掉小弟回血
- **合体**：小弟数量够多时合成大怪
- **不同兵种**：远程小弟 + 近战小弟混合

## 🛡️ 5. 坦克王

### 数值建议
```java
HT = 900;            // **超高血**
baseMin = 22; baseMax = 34;
baseMinDef = 18; baseMaxDef = 30;   // **超高防**
baseAcc = 30;  baseEva = 4;         // **低闪避**（让玩家打得中）
```

### 核心机制：减伤 + 反伤

```java
{
    properties.add(Property.BOSS);
    properties.add(Property.LARGE);        // 2×2 体积
    properties.add(Property.IMMOVABLE);    // 不可推动
}

@Override
public int defenseProc(Char enemy, int damage) {
    // 1) 固定减伤 40%
    damage = Math.round(damage * 0.6f);

    // 2) 反伤（近战才有）
    if (enemy != null && Dungeon.level.distance(pos, enemy.pos) <= 1) {
        enemy.damage(Random.NormalIntRange(4, 9), this);
    }

    return super.defenseProc(enemy, damage);
}

// ── 每回合缓慢回血（增加攻坚难度）──
@Override
protected boolean act() {
    if (HP < HT && Random.Int(3) == 0) {
        HP = Math.min(HT, HP + 5);
    }
    return super.act();
}
```

### 变体思路
- **护盾**：先打护盾，破盾后才能伤本体
- **阶段减伤**：血量越低防御越高
- **碾压**：移动时对路径上的人造成伤害

## 👑 6. 全能王（关底）

### 数值建议
```java
HT = 600;
baseMin = 24; baseMax = 40;
baseMinDef = 12; baseMaxDef = 22;
baseAcc = 36;  baseEva = 20;
```

### 核心机制：三阶段变身

```java
private int phase = 1;

@Override
public int defenseProc(Char enemy, int damage) {
    int newPhase = (HP * 3) / HT + 1;      // 100-67%=1, 66-34%=2, 33-0%=3
    if (newPhase > phase) {
        phase = newPhase;
        enterPhase(phase);
    }
    return super.defenseProc(enemy, damage);
}

private void enterPhase(int p) {
    switch (p) {
        case 2:
            yell("你们…惹恼我了！");
            sprite.flash();
            // 加速
            // Buff.affect(this, Haste.class, 30f);
            break;
        case 3:
            yell("见识真正的力量！");
            sprite.flash();
            // 狂暴：攻击力翻倍 + 招小弟
            baseMin *= 2; baseMax *= 2;
            summonBackup();
            break;
    }
}

/** 阶段 1：普通近战 */
/** 阶段 2：远程 + 近战混合 */
/** 阶段 3：狂暴 + 召唤 */
@Override
protected boolean act() {
    if (phase == 1) {
        return super.act();
    }
    if (phase == 2) {
        // 交替：一次法术，一次近战
        if (Random.Int(2) == 0 && enemy != null && enemySeen) {
            castSpell();
            spend(TICK);
            return true;
        }
        return super.act();
    }
    // phase 3
    if (Random.Int(4) == 0) {
        summonBackup();
        spend(TICK);
        return true;
    }
    return super.act();
}
```

### 变体思路
- **元素转化**：每个阶段换一种元素
- **复仇**：阶段切换时全屏 AOE
- **时间压力**：每阶段限时，超时全屏秒杀

| 定位 | HT | 伤害 | 防御 | 战斗时长目标 |
|---|---|---|---|---|
| 前期 Boss | 200-300 | 15-25 | 3-8 | 10-15 回合 |
| 中期 Boss | 300-500 | 20-30 | 6-14 | 15-25 回合 |
| 关底 Boss | 600-900 | 25-40 | 12-25 | 25-40 回合 |

**调整建议**：
1. **先定血量和伤害**，跑一次测试
2. 记录玩家用了多少回合、掉了多少血
3. **战斗太短** → 加血/加防；**太痛苦** → 减伤/降低命中
