## 二、Boss 类的结构（必须知道的 4 个钩子）

```java
public class YourBoss extends Boss {

    { /* 初始化：数值、属性、掉落 */ }

    protected boolean act()                        // 每回合 AI
    public boolean attackHook(Char enemy)          // 命中时的附加效果
    public int defenseProc(Char enemy, int damage) // 受伤时的减伤/反伤
    public void die(Object cause)                  // 死亡
}
```

### 2.1 初始化块 `{ }`

```java
{
    spriteClass = YourBossSprite.class;

    HT          = 300;          // 生命上限
    EXP         = 30;           // 击杀经验
    baseHT      = HT;           // 内部基准（必须等于 HT）

    baseMin     = 18;           // 伤害下限
    baseMax     = 28;           // 伤害上限
    baseAcc     = 32;           // 命中
    baseEva     = 18;           // 闪避
    baseMinDef  = 6;            // 防御下限
    baseMaxDef  = 14;           // 防御上限

    properties.add(Property.BOSS);
    alignment = Alignment.ENEMY;

    loot = Generator.Category.WEP_T5;
    lootChance = 1f;
}
```

### 2.2 `act()` —— AI 主循环

```java
@Override
protected boolean act() {
    // 返回 true  = 本回合已用掉（不再走默认逻辑）
    // 返回 false = 继续走父类默认（靠近 + 攻击）

    if (/* 要放技能 */) {
        doSkill();
        spend(TICK);        // 消耗一回合
        return true;
    }

    return super.act();     // 默认行为
}
```

**常用工具**：

| 代码 | 作用 |
|---|---|
| `spend(TICK)` | 消耗一回合 |
| `Dungeon.level.distance(pos, enemy.pos)` | 距离 |
| `enemySeen` | 是否发现敌人 |
| `Dungeon.level.heroFOV[pos]` | 玩家能否看见自己 |
| `Actor.findChar(cell)` | 某格上的角色 |
| `Dungeon.level.randomRespawnCell(this)` | 找个空位（-1 = 没位置） |

### 2.3 `attackHook()` —— 命中附加效果

```java
public boolean attackHook(Char enemy) {
    // 例：吸血
    HP = Math.min(HT, HP + 5);

    // 例：上 debuff
    Buff.prolong(enemy, Weakness.class, 5f);

    return false;
}
```

> ⚠️ **不能覆写 `attack(Char)`**（是 final）→ 用 `attackHook`

### 2.4 `defenseProc()` —— 减伤 / 反伤

```java
@Override
public int defenseProc(Char enemy, int damage) {
    damage = Math.round(damage * 0.7f);                    // 减伤 30%
    if (enemy != null) enemy.damage(Random.IntRange(2,5), this);  // 反伤
    return super.defenseProc(enemy, damage);
}
```

### 2.5 `die()` —— 死亡

```java
@Override
public void die(Object cause) {
    super.die(cause);          // 基类已自动 unseal，不要重复
    GameScene.bossSlain();
}
```

## 三、常用 Buff（负面状态）

```java
Buff.prolong(target, Weakness.class, 5f);      // 虚弱（降伤害）
Buff.prolong(target, Vulnerable.class, 5f);    // 易伤
Buff.prolong(target, Slow.class, 5f);          // 减速
Buff.prolong(target, Cripple.class, 5f);       // 残废
Buff.prolong(target, Blindness.class, 5f);     // 失明
Buff.prolong(target, Paralysis.class, 2f);     // 麻痹
Buff.prolong(target, Chill.class, 5f);         // 冰冻减速
Buff.prolong(target, Vertigo.class, 5f);       // 眩晕
Buff.affect(target, Poison.class).set(10);     // 中毒（10 点）
Buff.affect(target, Burning.class).reignite(target);  // 点燃
```

> ⚠️ `Buff.prolong()` **只对 `FlavourBuff` 子类有效**。
> 其他 buff 用 `Buff.affect(x, Y.class)` 或 `Buff.affect(x, Y.class).set(n)`。

## 五、召唤小怪

```java
private void summon() {
    Mob minion = new Bat();          // 任意怪

    int cell = Dungeon.level.randomRespawnCell(this);
    if (cell == -1) return;          // 没位置

    minion.pos = cell;
    GameScene.add(minion);
    minion.state = minion.HUNTING;   // 进入战斗状态
}
```

**统计自己的小弟**：
```java
int n = 0;
for (Mob m : Dungeon.level.mobs.toArray(new Mob[0])) {
    if (m != this && m.alignment == alignment) n++;
}
```

## 六、存档（有自定义字段时必须做）

```java
private int myCounter = 0;
private static final String MY_COUNTER = "myCounter";

@Override
public void storeInBundle(Bundle bundle) {
    super.storeInBundle(bundle);
    bundle.put(MY_COUNTER, myCounter);
}

@Override
public void restoreFromBundle(Bundle bundle) {
    super.restoreFromBundle(bundle);
    myCounter = bundle.getInt(MY_COUNTER);
}
```

> **如果跳过这步**：玩家中途退出再进，Boss 的自定义状态会丢失（可能出错）。

## 七、精灵类要点

```java
texture( "sprites/sixkings/yourboss.png" );   // 路径区分大小写

TextureFilm frames = new TextureFilm( texture, 16, 16 );   // 32px 图改 32,32

idle   = new Animation( 8, true );    idle.frames( frames, 0, 1 );
run    = new Animation( 12, true );   run.frames( frames, 2, 3 );
attack = new Animation( 12, false );  attack.frames( frames, 4, 5, 6 );
die    = new Animation( 10, false );  die.frames( frames, 7, 8, 9 );

play( idle );
```

**Animation 参数**：`new Animation(帧间隔, 是否循环)`
- 帧间隔：**数字越大越慢**
- 循环：`true` = 反复播放；`false` = 播一次停住

## 八、关卡类要点

```java
public class SixKingsLevel1 extends Level {

    @Override
    protected boolean build() {
        setSize( WIDTH, HEIGHT );
        // 画地形：map[i] = Terrain.WALL / EMPTY / ...

        set( entranceCell, Terrain.ENTRANCE );
        set( exitCell,     Terrain.EXIT );

        // ⚠️ 挑战区必须用 REGULAR_ENTRANCE
        transitions.add( new LevelTransition( this, entranceCell,
                LevelTransition.Type.REGULAR_ENTRANCE ) );
        transitions.add( new LevelTransition( this, exitCell,
                LevelTransition.Type.REGULAR_ENTRANCE ) );
        return true;
    }

    @Override
    protected void createMobs() {
        YourBoss boss = new YourBoss();
        boss.pos = /* 某格 */;
        GameScene.add( boss );
    }

    @Override protected void createItems() { }

    @Override public String tilesTex() { return "environment/tiles_halls.png"; }
    @Override public String waterTex() { return "environment/water0.png"; }
}
```

### 常用 `Terrain` 值

| 常量 | 含义 |
|---|---|
| `Terrain.WALL` | 墙 |
| `Terrain.EMPTY` | 空地 |
| `Terrain.EMPTY_DECO` | 装饰地面 |
| `Terrain.ENTRANCE` | 入口（上楼） |
| `Terrain.EXIT` | 出口（下楼） |
| `Terrain.WATER` | 水 |
| `Terrain.GRASS` | 草 |
| `Terrain.DOOR` | 门 |
| `Terrain.CHASM` | 深渊（掉下去） |

### 图形编辑辅助

```java
// 填矩形
for (int y = y0; y <= y1; y++)
    for (int x = x0; x <= x1; x++)
        map[y * WIDTH + x] = Terrain.EMPTY;

// 画墙边框
for (int i = 0; i < length(); i++) {
    int x = i % WIDTH, y = i / WIDTH;
    if (x == 0 || y == 0 || x == WIDTH-1 || y == HEIGHT-1)
        map[i] = Terrain.WALL;
}
```
