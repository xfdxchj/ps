## 阶段 2 · 第一个 Boss（跑通流程）

### 2.1 建目录

```powershell
$base = "E:\破碎的地牢\_EndShatteredBuild\core\src\main\java\com\shatteredpixel\shatteredpixeldungeon"
New-Item -ItemType Directory -Force -Path "$base\actors\mobs\bosses\sixkings" | Out-Null
New-Item -ItemType Directory -Force -Path "$base\sprites\sixkings" | Out-Null
New-Item -ItemType Directory -Force -Path "$base\levels\boss" | Out-Null
```

### 2.2 复制模板并改名

把 `templates/BossTemplate.java` 复制到 `actors/mobs/bosses/sixkings/SorcererKing.java`，然后：

**全局替换**：
| 原 | 新 |
|---|---|
| `SorcererKing` | `SorcererKing`（保持不变，或改成你的名字） |
| `SorcererKingSprite` | 你的精灵类名 |
| `sorcererking` | 你的贴图/键名 |

同样处理精灵模板 → `sprites/sixkings/SorcererKingSprite.java`。

### 2.3 编译

```powershell
cd E:\破碎的地牢\_EndShatteredBuild
& .\tools\localcompile.ps1
```

**预期**：`COMPILE OK`

**如果失败**：看 `E:\破碎的地牢\_javac_out\javac.log` 的 `symbol:` 行，通常是缺 import。

### ✅ 阶段 2 验证
编译通过。

## 阶段 3 · 剩下五个

**复制第一份改改就行**：

```
SorcererKing.java  →  ArcherKing.java    （远程）
                   →  PlagueKing.java    （Debuff）
                   →  SummonerKing.java  （召唤）
                   →  TankKing.java      （坦克）
                   →  OmniKing.java      （全能）
```

**每个的主要改动**（参考 `03-六王配方.md`）：

| Boss | 改什么 |
|---|---|
| **ArcherKing** | 加 `IDEAL_RANGE` 逻辑 + `retreat()` |
| **PlagueKing** | `attackHook` 里加随机 debuff |
| **SummonerKing** | 加 `summon()` + 数量上限 |
| **TankKing** | 调高 HT/防御 + `defenseProc` 减伤反伤 |
| **OmniKing** | 加 `phase` 字段 + `enterPhase()` |

**每加一个就编译一次**，别攒着。

### ✅ 阶段 3 验证
6 个类都能编译。

## 阶段 5 · 注册挑战区

改 `endcontent/challenge/ChallengeArea.java`：

```java
// 1) 注册
public static final ChallengeArea SIX_KINGS = new ChallengeArea(7, "六大天王", 7, true);

// 2) 加进 ALL
public static final ChallengeArea[] ALL = { HOLLOW, GALAXY, IBERIA, GAVIAL, SIESTA, SIX_KINGS };

// 3) 路由
if (areaId == SIX_KINGS.id) {
    switch (floorIn) {
        case 0: return new com...levels.boss.SixKingsLevel1();
        case 1: return new com...levels.boss.SixKingsLevel2();
        case 2: return new com...levels.boss.SixKingsLevel3();
        case 3: return new com...levels.boss.SixKingsLevel4();
```

## 阶段 6 · 文案

在 `assets/messages/actors/actors.properties` 加 6×3 = 18 个键：

```properties
actors.mobs.bosses.sixkings.sorcererking.name=焚天法师
actors.mobs.bosses.sixkings.sorcererking.desc=...
actors.mobs.bosses.sixkings.sorcererking.notice=...
# ... 其余 5 个
```

**自查**：
```powershell
cd E:\破碎的地牢
python _tools\find_nofound.py
```
→ 必须**零缺失**。

## 阶段 7 · 测试与平衡

### 7.1 构建运行

```powershell
& E:\破碎的地牢\_EndShatteredBuild\tools\runlocal.ps1
```

### 7.2 测试路径

1. 新游戏 → 勾选「六大天王」
2. 用**深渊传送符**跳到 25F / 26F
3. 依次打六个王

### 7.3 平衡调整

| 症状 | 调整 |
|---|---|
| **死太快** | 提高 `HT`、`baseMinDef/baseMaxDef` |
| **打不动** | 降低 `HT`、`baseMinDef/baseMaxDef` |
| **玩家秒杀** | 提高防御 + 加 `defenseProc` 减伤 |
| **Boss 打不中玩家** | 提高 `baseAcc` |
| **Boss 太强** | 降低 `baseMin/baseMax`、`baseAcc` |

**记录**：每个 Boss 打了几回合、玩家掉多少血。目标：
- 前期王：10-15 回合
- 中期王：15-25 回合
- 关底王：25-40 回合

## 🆘 卡住了怎么办

| 症状 | 查 |
|---|---|
| 编译失败 | `E:\破碎的地牢\_javac_out\javac.log` 的 `symbol:` 行 |
| 显示 `NO TEXT FOUND` | `python _tools\find_nofound.py` |
| 崩溃 `frame is null` | 贴图帧数是否够（见 `05-避坑清单.md` 坑 1） |
| 踩楼梯没反应 | 过渡类型是否 `REGULAR_ENTRANCE`（坑 6） |
| 进入就弹到下一层 | 入口/出口格是否相同（坑 7） |
| 看不到你的区域 | `ALL` 数组是否加了（阶段 5.2） |
