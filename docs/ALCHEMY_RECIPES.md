# 炼金配方总表（End 扩展）

> 数据来源：`core/src/main/java/.../items/Recipe.java`、`endcontent/evolved/*`、`endcontent/items/InfinityRecipes.java`、`items/changer/GunBlueprint.java`、`items/spells/*`、`items/GunSmithingTool.java`。
> 所有配方都在**炼金台**里合成；`cost` 为 0 的配方不消耗额外炼金能量，只消耗材料。

---

## 一、无尽体系（挑战 214「无尽碎片」）

| 配方 | 材料 | 产物 | 说明 |
|---|---|---|---|
| 分解 | 任意**已鉴定、未诅咒**的武器/护甲 ×1 | 无尽碎片 | 数量 = `clamp(装备阶数, 1, 5)`，即 1 阶给 1 个、5 阶给 5 个 |
| 取核 | **15 级及以上**的武器/护甲/戒指/投掷武器 ×1 | 对应类型无尽核心 | 类型：剑（近战武器）/ 甲（护甲）/ 戒（戒指）/ 弓（可堆叠投掷武器） |
| 铸锭 | 无尽碎片 ×100（同一格可堆叠） | 无尽锭 ×1（余数保留） | 100 碎片 = 1 锭 |
| 顶级装备 | 无尽锭 ×2（同一格堆叠） + 对应核心 ×1 | 对应顶级装备 | 共 2 格；**核心类型决定产物**，不再需要样品装备 |

**顶级装备对照（由核心类型决定）：**

| 核心类型 | 产物 |
|---|---|
| 剑核心 | 寰宇支配之剑（挑战 211） |
| 甲核心 | 虚空不灭之甲（挑战 212） |
| 戒核心 | 轮回噬灭之戒（挑战 213） |
| 弓核心 | 天堂陨落长弓（挑战 215） |

> 注意：挑战 211/212/213/215 还要求先勾选 **214**（`p:214` 前置）。

## 三、枪械体系（挑战 229「枪械工坊」）

| 步骤 | 材料 | 产物 |
|---|---|---|
| ① 升级之尘 | 强化符石 ×1 + 液态金属 ×20 | 升级之尘 ×3 |
| ①' 改造工具 | 强化符石 ×1 + 液态金属 ×20 | 枪械改造工具 ×1 |
| ② 进化法术 | 嬗变卷轴 ×1 + 不稳定法术 ×1 | 进化法术 ×1 |
| ③ 枪械蓝图 | **T5 枪** ×1 + 升级之尘 ×1 + 进化法术 ×1 | 枪械蓝图 ×1（绑定对应 T6） |
| ④ 进阶 | 对**对应 T5 枪**使用枪械蓝图 | 该枪的 T6 战术型 |

- ① 与 ①' 材料相同，在炼金台里由玩家选择要哪个产物。
- ④ 成功率 = `1 - 0.2 × (T6 阶 - T5 阶) + 0.1 × 蓝图强化等级`，即 +0 时 **80%**，每强化蓝图 1 级 **+10%**。
- 进阶后**保留强化等级与全部改造件**（枪管/弹匣/子弹/重量/附件/附魔/蚀刻）。
- 枪械改造工具用于给枪装改造件，不参与 T6 进阶。
- T6 共 5 把：战术突击步枪（AR）、战术狙击步枪（SR）、战术手枪（HG）、战术榴弹发射器（GL）、战术火箭发射器（RL）。
