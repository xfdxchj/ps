## 零、通用约定（每条都适用）

### 0.1 判断方式

新规则用 **表 ID** 判断，不要用旧的 `int` 位：

```java
// 正确：按表 ID 判断（新框架）
if (Dungeon.isChallengedId(9)) { ... }

// 也正确：按掩码判断
if (Dungeon.challengeMask.has(9)) { ... }

// 错误：这些是旧 int 位，语义完全不同（见下方警示）
if (Dungeon.isChallenged(512)) { ... }
```

> ⚠️ **旧 int 位与新规则无关**。旧位只有 12 个（`NO_FOOD=1` … `INFLATION=2048`），
> 且**没有**对应本表这 35 条的位。勾选本表规则**不会**改变任何旧 `int` 位。

### 0.2 每条规则的收尾工作（缺一不可）

| 步骤 | 内容 |
|---|---|
| 1 | `ChallengeRegistry` 里把该条的 `state` 从 `STATE_PENDING` 改为 `STATE_DONE` |
| 2 | 补 `effect` 字段（原表描述原文），供详情弹窗显示 |
| 3 | `windows.properties` + `windows_zh.properties` 补 `challenges.<key>` 与 `challenges.<key>_desc` |
| 4 | 编译：`.\tools\localcompile.ps1` 必须 `COMPILE OK` |

> 注意：**不需要**给易档规则加 `legacyBit` —— 它们没有旧 `int` 位，
> 加了反而会让 `toLegacyInt()` 产生错误映射。

### 0.3 数值写法约定

- 概率用 `Random.Int(100) < N` 或 `Random.Float() < N/100f`（与仓内既有写法一致）
- 百分比增减直接乘系数（如 +20% → `* 1.2f`）
- **所有涉及伤害/血量的取整用 `Math.round` 或 `(int)`，与周边代码保持一致**

## 一、战斗类（16 条）

### ID 9 狂暴 · Lv2 · 怪物强化
- **原文**：怪物受击后获得 20% 攻击提升
- **行为**：怪物每次受到伤害后，攻击力 +20%
- **叠加**：**不叠加**（保持 +20%，不累乘）
- **持续**：2回合
- **落点**：`Mob.damage()` 覆写处设标记；`Char.damageRoll()` 里若标记存在则 `*1.2f`
- **边界**：只对 `Alignment.ENEMY` 生效；Boss 也生效

### ID 10 巨型化 · Lv2 · 怪物强化
- **原文**：部分怪物获得更高生命值及更大体型
- **行为**：*怪物13%概率）HP/HT ×1.5，视觉缩放 ×1.2
- **触发时机**：怪物**生成时**决定（不是每回合判定）
- **落点**：`Mob` 生成路径（`MobSpawner` 或 `Level.createMobs` 之后统一遍历）
- **边界**：Boss、NPC 不参与；已放大过的不重复放大

### ID 11 脆弱 · Lv2 · 双刃剑
- **原文**：玩家与怪物受到的伤害提高 13%
- **行为**：**双方**受到的最终伤害 ×1.13
- **落点**：`Char.damage()` 伤害管线的最终取整前
- **边界**：对玩家和怪物**都**生效（这才是"双刃剑"的含义）；
  不作用于 `LifeLink` 分摊、不作用于固定伤害（如饥饿）

### ID 12 玻璃大炮 · Lv2 · 双刃剑
- **原文**：玩家攻击提高 20%，生命降低 13%
- **行为**：玩家伤害 ×1.2；玩家 **HT 上限** ×0.87（当前 HP 按比例同步降低）
- **落点**：伤害在 `Hero.damageRoll()` 或 `Char.damage()` 攻击方侧；HT 在英雄初始化处
- **边界**：**只影响玩家**，不影响怪物；HT 降低后不低于 1

### ID 13 狂热 · Lv2 · 怪物强化
- **原文**：怪物攻击后攻速提升 13%
- **行为**：怪物每次**成功攻击**后，其 `speed()` ×1.13
- **叠加**：**可叠加**——建议封顶 3 层（×1.44）5回合持续
- **落点**：`Mob.attackProc()` 或 `Mob.attack()` 后置钩子；`Mob.speed()`
- **边界**：只在攻击**命中**时触发

### ID 14 精英强化 · Lv2 · 怪物强化 ✅已实装
- **原文**：精英怪获得 20% 属性提升
- **行为**：精英怪（`ChampionEnemy`）**HP/HT、伤害、命中、闪避 各 ×1.2**
- **落点**：
  - HP/HT → `ChampionEnemy.rollForChampion()` 里 `Buff.affect` 之后（精英化的唯一时刻）
  - 伤害 → `Char.attack()` 的 `ChampionEnemy` 循环内（调用侧相乘）
  - 命中/闪避 → `Char.hit()` 的 `acuRoll` / `defRoll` 处
- **关键细节**：`ChampionEnemy` 的子类（Blazing/Projecting…）都是**直接 return 常量**、
  不调 `super`，所以**改基类方法无效**，必须乘在调用侧。
- **关键细节**：加血前必须判断 `m.buff(buffCls) == null` ——
  `Buff.affect` 对已有该 buff 的目标直接返回旧的、不做任何事，
  不判断就会在重复调用时**给同一只怪叠加多次血量**。
- **联动**：与 4 精英迁徙 / 75 精英地牢 叠加（它们决定"谁是精英"，本条决定"精英多强"）

- **行为**：**玩家**每回合 13% 挂 `Chill`，2% 挂 `Frost`
- **落点**：`Hero.act()` 或统一回合钩子

### ID 90 雷暴 · Lv2 · 双刃剑
- **原文**：每回合 5% 概率闪电随机劈中角色，造成伤害并可能点燃
- **行为**：每回合 5% 概率随机选一个角色，造成闪电伤害并有概率点燃
- **伤害公式（已定）**：`3 * 层数 / 5`（整数运算）

    这是整数截断的必然结果，实装时**不要**改成至少 1 点，除非另行确认。
- **落点**：统一回合钩子
- **边界**：可能劈中玩家**或**怪物（双刃剑）；伤害量按上式随层数缩放
