# 冒烟测试清单

每次改完一个系统，按这个顺序跑一遍。目标是「改动没把旧东西弄崩」，不是测全部内容。

## 0. 编译前

- [ ] 新增/删除 Java 文件后，重新生成 `_javac_out2/sources.txt`。
- [ ] **删除类之后，必须清掉输出目录里的旧 `.class`**（`_tmp/classes_all`、构建 jar）。
      旧 class 会继续被反射/读档找到，掩盖「类已删除」的 bug。
- [ ] `javac` 输出 0 错误。警告可以暂时忽略，但不要新增。

## 1. 启动

- [ ] 主菜单正常显示，音乐正常。
- [ ] 不出现 `Badges.restore` / `Catalog.restore` / `Reflection` 异常。

## 2. 旧存档读档

- [ ] 打开一个删过物品/徽章/挑战的旧档。
- [ ] 能进游戏；缺失内容直接跳过，不崩。
- [ ] 图鉴 / 统计 / 挑战窗口能正常打开。

## 3. 新开局

- [ ] 每个职业各开一局，能进 1 层。
- [ ] 挑战窗口能打开、切分类、翻页、看详情、勾选/取消、前置弹窗。
- [ ] 关闭挑战窗口后，原来列表位置点一下：不应弹详情、不应有声音。

## 4. 战斗

- [ ] 近战命中 / 暴击 / 伤害数字。
- [ ] 投掷武器命中。
- [ ] 每类法杖各放一次（含进化法杖两种形态）。
- [ ] 技能 / 护甲技能各放一次。
- [ ] 检查 logcat 无异常。

## 5. 成长与炼金

- [ ] 升级卷轴强化武器/护甲/戒指。
- [ ] 法杖充能和升级。
- [ ] 普通炼金：药水、卷轴、炸弹。
- [ ] 挑战专属炼金：枪械、进化法杖、无尽、原神词条石。
- [ ] 炼金产物名称和说明正常（不是 NO TEXT FOUND）。

## 6. 存读档

- [ ] 当前局面存档，回主菜单，再读回来。
- [ ] 位置、生命、背包、挑战、词条、气体/区域状态一致。
- [ ] 读档后 logcat 无异常。

## 7. 收尾

- [ ] logcat 过滤 `GAME` / `Exception` / `WndChallenges`，确认没有新增堆栈。
- [ ] 记录本次改动影响范围，供下次回归。
